# Supported versions

Only combinations in this table are supported. Update to the newest RTO build before reporting a
problem.

<!-- supported-table:start -->
| Minecraft | Loader | Java | Latest | Recommended | Support |
| --- | --- | --- | --- | --- | --- |
| 26.3 | NeoForge 26.3.0.84 or later | 25 | 0.1.0 | 0.1.0 | Stable |
<!-- supported-table:end -->

RTO must be installed on both the client and the server; a client without it cannot join a server
that has it. Fabric, Forge, Bukkit, Spigot, and other Minecraft versions are not supported.

Some other mods need a newer NeoForge build than RTO does. Use a NeoForge 26.3 build that satisfies
every mod in your pack.
