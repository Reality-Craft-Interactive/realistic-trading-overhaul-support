# Security policy

Do not disclose a suspected security vulnerability in a public issue or Discussion.

Use GitHub's **Report a vulnerability** button on this repository's Security page. Include:

- affected RTO, Minecraft, and NeoForge versions;
- client, server, or both;
- impact and realistic attack conditions;
- minimal reproduction steps; and
- logs or a proof of concept with secrets removed.

The report will remain private while it is investigated. Public disclosure should wait until a fix
or mitigation is available.
